# M1-16 — Value objects: `Money`, `Quantity`, `SeatLocation`, `TimeWindow`

Status: needs-triage

## Задача

Сделать невозможные значения непредставимыми в типах. `Money` — сумма и валюта вместе, с
замкнутой арифметикой: сложить доллары с евро не должно компилироваться или должно бросать.
`Quantity` — целое больше нуля, в котором `-1` не существует. `TimeWindow` — конец всегда позже
начала. `SeatLocation` — секция, ряд, номер.

Объекты неизменяемые, сравниваются по значению, валидируют себя в конструкторе и не знают ни
про базу, ни про NestJS.

## Definition of Done

- Все четыре VO лежат в `domain/`, тесты гоняются **без базы и без Nest**
- Невалидное значение невозможно создать: конструктор бросает, а не чинит молча
- Неизменяемость реальная: `money.amount = 100` не компилируется или не имеет эффекта
- Равенство — по значению, и это покрыто тестом
- Арифметика `Money` не теряет копейки: есть тест на деление и округление

## На что смотрю на ревью

- `Money` внутри — не `number` с плавающей точкой. Классика `0.1 + 0.2` должна быть закрыта тестом
- Округление — это решение, а не деталь: назвать правило и где оно применяется
- VO с сеттерами — не VO
- Тест «создали и проверили геттер» ничего не доказывает; тест обязан проверять **отказ**
  создать невалидное значение
