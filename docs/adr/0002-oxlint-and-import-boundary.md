# ADR-0002 — Линтер oxlint; граница между приложениями держится на правиле импортов

Status: accepted
Date: 2026-09-11

## Контекст

В монорепо два приложения: `apps/server` (NestJS) и `apps/web` (TanStack Start). Им нужен
линтер и нужна граница: веб не должен импортировать исходники сервера и наоборот — контракт
между ними идёт через спеку OpenAPI (`DTO → спека → типы веба`, см. `M0-01`, `M2-06`, `M9-02`).

Изначально в `M0-01` был выбран ESLint. Роман поменял решение на **oxlint** (2026-09-11):
скорость и отсутствие необходимости поднимать flat-config с плагинами под два разных
окружения. Конфиг линтера и скрипты — по папкам приложений, корень только агрегирует.

## Решение

**Линтер — oxlint.** Общая база `apps/.oxlintrc.base.json`, в каждом приложении
`.oxlintrc.json` с `extends` на неё и правилами своего окружения.

**Граница между приложениями — правило `no-restricted-imports` с `patterns`** (не `paths`:
там точные specifier'ы, глобы не работают). В каждом приложении два шаблона:

- `regex` на относительный выход за пределы приложения — `^\.\.(/\.\.)*/(apps/)?web/`
- `group` на любой путь, содержащий `**/apps/web/**` и алиасы чужого приложения

Плюс `typescript/no-require-imports` в общей базе: `no-restricted-imports` **не видит**
`require()` (проверено), а оба приложения ESM — `require` в них нелегитимен в принципе.
Динамический `import()` правило видит.

## Следствия

- Правило `typescript/consistent-type-imports` включено только в web. В server его включать
  нельзя: при `emitDecoratorMetadata` перевод конструкторных зависимостей в `import type`
  стирает метаданные и ломает DI в рантайме.
- Дефолтное имя конфига — `.oxlintrc.json`. Файл с другим именем (`oxlint.json`) молча
  игнорируется: `oxlint --print-config` — единственный способ убедиться, что конфиг вообще
  прочитан.
- Сгенерированный код (`**/*.gen.ts`, `**/generated/**`) исключён из линта и из Prettier,
  чтобы не шумел в diff. Это же место для будущих типов из OpenAPI.
- Дрейф контракта (кто-то поменял DTO и не перегенерировал типы) правилом не ловится —
  это задача CI в `M7-06`.
